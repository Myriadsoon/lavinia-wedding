# Codex Working Instructions

## Default behaviour

This project is being developed as both a working Drupal project and a
learning exercise.

By default, treat my requests as requests for analysis, explanation,
investigation or planning.

You may read and inspect files within this project as necessary.

Do not create, modify, rename or delete files unless I explicitly ask you
to implement a change.

Do not run commands or programs, including DDEV, Drush, Composer, npm or
Git commands, unless I explicitly authorise this.

## Implementation

When I explicitly ask you to implement a change:

- Modify only the files necessary for the agreed task.
- Do not make unrelated changes, improvements or refactoring.
- Explain what you changed and why.
- Identify the files changed.
- Tell me what should be tested.

When proposing changes, explain the relevant Drupal concepts and
architectural reasoning so that I can understand the implementation.

## Git and external access

Do not commit, push, pull, merge, rebase, switch branches, or otherwise
modify Git state unless I explicitly request the particular operation.

Do not access GitHub, production hosting, cPanel, SSH, external
applications, or resources outside this project unless I explicitly
authorise it.

If it is unclear whether I have authorised an action, ask before acting.
